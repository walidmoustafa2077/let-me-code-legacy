Route a request to one agent

The orchestrator reads the request, names the work and hands it to a specialist. Nobody reads the whole repository, and no two agents edit the same file at once.

Does it need an API key of its own?

No. It runs on the model you already use in opencode. The server only needs the port, and a password if you expose the port beyond your machine.

Where do the agents work?

In worktrees under your project folder on your machine. Each agent gets its own checkout, so two agents never edit the same file, and you can read every diff locally.

Can an agent push to main?

The git agent commits verified work to a branch and stops. Pushing and opening a pull request stay with you, and a failing test blocks the commit.

What do the agents cost?

Only the model calls opencode already bills for. The delegation server is a local Node process, and the agents and skills are plain files in your repository.

How do I remove the agents?

Delete the two folders the installer wrote, .opencode/agent and .opencode/skills, and the server entry from your opencode config. Nothing else is touched.
